# Описание проекта

Учебная реализация небольшого SPA react приложения для отслеживания/создания/изменения карточек технологий с использованием Material UI, React Routing, работа и мок API.

https://maninspacee.github.io/react-fab

Основные технологии:
- React
- JavaScript
- MaterialUI
- Сборка/инструменты: Vite / Create React App

Краткий запуск (пример):
1. Клонировать репозиторий:
   git clone https://github.com/ManInSpacee/react-fab.git
2. Установить зависимости:
   npm install
3. Запустить:
   npm start

Примечание: проект — учебный, сосредоточен на реализации SPA приложения для отслеживания технологий и демонстрации взаимодействия с состоянием/пропсами.
